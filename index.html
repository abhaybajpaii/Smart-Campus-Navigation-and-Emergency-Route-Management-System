DSA Academic Project Portfolio & Setup Guide

1. Realized Data Structures

  • Campus Graph (Adjacency List): Managed via a structured Node & Edge map allowing dynamic edge operations (blocking, unblocking).
  • Custom HashMap: Maps arbitrary string labels (e.g. "Canteen") to array node ID buckets, simulating hashing algorithms and collisions dynamically.
  • Binary Min-Heap Priority Queue: Custom array-based tree implementation driving Dijkstra's shortest paths without third-party frameworks.
  • Navigation History Stack: LIFO buffer capturing paths computed, letting you rewind and review traces in real-time.
  • Buffer Dispatcher Queue: FIFO structure allowing asynchronous path inquiries from around the college ecosystem.

2. Local Run & Deployment

Since this academic client contains fully compiled structures in client-side Javascript, it runs natively on any modern browser! You can run it instantly without configuring physical virtualenvs or Flask servers.

# To run instantly without setup:
Double-click standard index.html directly in your browser.
# If a Python Flask Backend is absolutely required:
1. Save this script inside standard flask folders.
2. Map endpoints matching: /api/shortest-path, /api/block-road, etc.
